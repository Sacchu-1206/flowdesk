# FlowDesk

FlowDesk is a modern multi-page SaaS marketing website built using React and Vite.

## Features

- Responsive Design
- SEO Optimized
- React Router
- Reusable Components
- Accessible HTML
- Product Page
- Pricing Page
- Contact Page

## Tech Stack

- React
- Vite
- React Router DOM
- React Helmet Async
- Lucide React
- CSS3

## Pages

- Home
- Product
- Pricing
- Contact

## Installation

npm install

npm run dev

## Build

npm run build
